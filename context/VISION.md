# Vision

alXns Command Center es una PWA personal, privada y responsive para centralizar infraestructura self-hosted, estado de aplicaciones, accesos contextuales y objetivos personales.

La primera iteración prioriza una experiencia sencilla con Inicio, Retos y Enlaces. La UI debe renderizar pronto, tolerar fallos de red y mantener separadas presentación, dominio, preferencias, integraciones e infraestructura.

Este documento expresa el concepto de producto. Los detalles implementados viven en requisitos y código; las tareas y propuestas viven en `Issues/`.
