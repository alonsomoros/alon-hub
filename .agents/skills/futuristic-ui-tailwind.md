# alXns UI

La dirección actual es calmada, sencilla y agradable: fondo claro suave, superficies blancas, bordes ligeros, verde salvia como acento y tarjetas redondeadas. El logo y el nombre tienen prioridad visual. Evitar exceso de dashboards, etiquetas técnicas, cursivas decorativas, halos intensos y datos secundarios en la primera impresión.

Usar componentes reutilizables y responsive. Los servicios se representan como logos clicables con estado visual; los logros como progreso por color; los enlaces como botones limpios. La futura preferencia de tema debe permitir `soft`, claro y oscuro sin acoplar los componentes a un único color.
